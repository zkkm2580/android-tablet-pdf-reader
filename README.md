# 平板 PDF 阅读器 (Tablet PDF Reader for Android)

专为安卓平板（8~14 英寸大屏横竖屏）设计的原生高清 PDF 阅读器，支持 **PDF 内嵌目录（TOC）解析**、**个性化书签与批注**、**左右或上下划动翻页切换**、**双指缩放与护眼模式**，并通过 **GitHub Actions** 自动云端编译生成可直接安装的 APK。

---

## ✨ 核心功能特性

1. **平板大屏分栏设计**
   - 左侧配备 320dp 黄金比例「**目录 / 书签**」导航抽屉，支持横屏常驻对照阅读，也可一键收起进入全屏沉浸阅读模式。
   - 横竖屏旋转无缝衔接（不丢失当前阅读页码与缩放状态）。
2. **左右划动 & 上下划动翻页自由切换**
   - 基于 `ViewPager2` 实现丝滑翻页，点击顶部工具栏 `⇄ 左右翻页` / `⇅ 上下翻页` 按钮即可实时切换横向书本翻页或纵向连续翻页。
   - 底部配备快速翻页进度滑块（SeekBar）与「输入页码快速跳转」弹窗。
3. **多级目录（TOC）智能解析**
   - 基于 `PDFBox-Android` 自动解析 PDF 内嵌章节树（Document Outline），支持多级缩进展示与当前所属章节高亮。
   - 若打开的扫描版 PDF 未内嵌目录，自动生成全文档页码快速索引。
   - 支持按关键字或页码实时过滤检索目录。
4. **书签与阅读备注管理**
   - 点击顶部 `☆ 添加书签` 或侧边栏书签按钮，可为当前页添加自定义书签标题与阅读笔记。
   - 每本 PDF 的书签与上次阅读进度自动持久化保存，下次打开自动续读。
5. **高清渲染、手势缩放与平板护眼模式**
   - 双指捏合无级缩放（`1.0x ~ 4.0x`）与双击快速放大/复位，放大时自由拖拽查看细节，复位后滑动自动翻页。
   - 内置 **☀ 标准日间**、**📜 暖色羊皮纸护眼**、**🌙 夜间深色反相** 三种阅读主题。
   - **内置多章节示例 PDF**：安装打开即可直接体验带多级目录与书签的完整说明书文档。

## 🚀 自动编译 APK 与安装说明

本项目已配置 GitHub Actions 工作流（[`.github/workflows/build-apk.yml`](<.github/workflows/build-apk.yml>)）：
- 每次推送代码到 `main` / `master` 分支或手动触发 `Run workflow` 时，GitHub 云端会自动配置 JDK 17、Android SDK 与 Gradle 8.7 并编译 Debug 与已签名 Release APK。
- 编译完成后：
  1. 在仓库右侧 **Releases** 页面可直接下载 `TabletPdfReader-v1.0.0-release.apk` 安装到安卓平板；
  2. 也可在仓库顶部 **Actions** -> 最新构建任务底部的 **Artifacts** 中下载 `TabletPdfReader-APK`。
